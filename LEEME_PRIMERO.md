# Kit de Trazo para Claude Code

Este kit tiene todo lo que Claude Code necesita para construir la app. Tú no tienes que leerlo entero: los pasos manuales están en el Word "Trazo - lo que tienes que hacer tú".

## Qué hay
- `CLAUDE.md`: las reglas del proyecto. Claude Code lo lee solo al empezar cada sesión.
- `docs/00_PLAN_Y_PROMPTS.md`: las 11 etapas (más una opcional, la 4b) y **el mensaje exacto que tienes que pegar** en cada una.
- `docs/01` a `docs/08`: especificaciones (arquitectura, diseño, tracer, análisis, ayuda, compilación, pruebas y desglose del vídeo de referencia).
- `docs/09_GUIA_JAVIGGIL.md`: qué se ha tomado de la guía de javiggil del tracer, dónde está cada parte y qué se dejó fuera (y por qué).
- `design/maqueta.html`: ábrela con doble clic para ver cómo será la app. `design/capturas/` tiene las mismas pantallas en imagen.
- `design/demo/`: imágenes de demostración para las capturas automáticas.
- `design/AppIcon-1024.png`: icono de la app.

## Cómo empezar
1. Descomprime este kit dentro de la carpeta del proyecto (por ejemplo `C:\Proyectos\trazo`). `CLAUDE.md` tiene que quedar en la raíz de esa carpeta.
2. Abre la carpeta en VS Code (Archivo > Abrir carpeta).
3. Abre Claude Code en VS Code y pega el mensaje de la Etapa 0 de `docs/00_PLAN_Y_PROMPTS.md`.
4. Una etapa por sesión. Escribe `/clear` antes de empezar la siguiente.
